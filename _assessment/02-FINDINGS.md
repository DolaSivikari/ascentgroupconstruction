# 02 — Findings (prioritised)

Audit of the Ascent Group Construction website repository (read-only). One table, sorted by severity. Every row cites file:line (or says Unknown and what would answer it). Detail and context for each area is in `01-REPORT.md` (inventory and run results) and `03-PAGE-AUDIT.md` (page-by-page, which uses these IDs).

**Severity definitions.** *Critical* = hurts trust or blocks leads/SEO right now. *High* = significant lost opportunity. *Medium* = should fix soon. *Low* = polish. **Effort:** S = under a day, M = a few days, L = a week or more.

**Counts:** Critical 6, High 13, Medium 23, Low 8 — 50 findings.

**Reading note.** The "Issue" column states facts (what the code or the browser run showed). "Why it matters" and "Suggested fix" are my judgement. Where a finding depends on live data the repository does not contain, the Issue says **Unknown** and the list at the end names what would answer it. Nothing in the repository was modified.
